# 가독성·학습 UX 디자인 개선 설계 (2026-06-11)

## 배경 / 문제 진단

2026-05-24 UI 개편(라이트/다크 팔레트·카드 리뉴얼) 이후에도 남은 가독성 문제:

1. **콜아웃 남발**: "📌 동향/주요 변화" 뉴스성 콘텐츠가 전부 노란 `warning-box`로 표시되어
   본문 페이지가 경고색으로 도배됨. 의미(동향)와 색(경고)이 불일치.
2. **페이지 내 내비 부재**: 본문 페이지가 길지만(수백~2천 줄) 페이지 내 목차·읽기 위치 표시 없음.
3. **본문 타이포**: h3/h4 위계가 약하고, 행간·측정폭·리스트 간격이 한글 장문 기준 미세 조정 안 됨.
4. **표**: 행 수가 많은 비교표에서 헤더가 사라지고 줄 추적이 어려움.

## 결정 사항

- 방향: **가독성·학습 UX 중심** (무드 전환 아님 — 현 블루 팔레트·구조 유지)
- 범위: **CSS + main.js + 38개 HTML 마크업 재분류 포함**
- 접근: **A. 콜아웃 재설계 + 리딩 레이어** (사용자 승인 완료)

## 설계

### 1. 콜아웃 시스템 재설계
- 4종 체계:
  - `trend-box` (신규): 동향/뉴스. 중립 블루 톤(라이트: 연블루 배경+블루 좌측 보더 / 다크: 딥블루).
  - `warning-box`: 진짜 주의·경고만(EOL 마감, 보안, 비용 함정). 현행 노랑 유지.
  - `info-box`: 개념·팁. 인라인 스타일 변형(`border-left:4px solid #4caf50` 등)을
    `.info-box.success`, `.info-box.accent` 클래스로 흡수.
  - 공통: 박스 첫 `<strong>` 제목 줄을 캡션 스타일(크기↓·자간↑)로, 연속 박스 간 간격 확대.
- HTML 재분류: "📌 …동향/주요 변화/업데이트" 패턴의 `warning-box` → `trend-box`
  (스크립트 치환 + 수기 검수. 진짜 경고는 warning 유지).

### 2. 본문 타이포그래피
- 본문 단락·리스트 측정폭 ~72ch 제한 (컨테이너 960px 유지, 표·다이어그램·코드 전폭 허용).
- 본문 행간 1.75, 단락/`li` 간격 정비.
- h3: 섹션 넘버 강조 + 하단 보더. h4: 크기·상단 여백 차등.

### 3. 리딩 레이어 (main.js)
- 페이지 내 TOC: h3/h4 자동 수집 → ≥1280px 우측 플로팅 미니 목차 + 스크롤 스파이,
  <1280px 본문 상단 접이식(details). 홈(index.html)은 제외.
- 읽기 진행바: 상단 고정 3px 프로그레스.

### 4. 표 가독성
- 스티키 표 헤더(`thead th { position: sticky }`), 지브라 줄무늬, 좁은 화면 가로 스크롤 래퍼.

### 5. 검증
- Playwright: 라이트/다크 × 홈/본문(module9-1)/표 많은 페이지(module8-1) 스크린샷 비교.
- 콘솔 오류 0, 다크 테마 색 대비 확인, `npm run check:links` 통과.

## 비범위 (YAGNI)
- 폰트 교체, 무드/팔레트 전환, 모듈별 진도 트래킹 강화, 읽기 시간 표시 — 이번 작업에서 제외.
